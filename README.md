# TikVoid

TikVoid — Clean TikTok Video Saver.

Live demo: https://tikvoid.vercel.app

Short description
- Download TikTok videos without watermark in HD. Fast, mobile friendly, and free — no app needed.

Features
- No watermark downloads
- HD video support
- Works on mobile & desktop
- Lightweight static site, deployable on Vercel/Netlify

Usage / Demo
1. Open https://tikvoid.vercel.app
2. Paste a TikTok video link and hit Download.
